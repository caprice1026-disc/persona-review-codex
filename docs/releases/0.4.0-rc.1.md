# Persona Review 0.4.0-rc.1 — private draft

Draft release copy only. No release, tag, or publication has been created.
Keep unpublished until the candidate has passed independent review and CI.

This preview makes local installation easier with a ready-made marketplace ZIP,
English/Japanese setup instructions, runtime-detecting launchers, and reproducible
distribution checks. Persona Review keeps technical findings, severity, evidence,
and uncertainty unchanged while presenting them in a selected character voice.

## Included

- Apache-2.0 license and explicit local-execution metadata.
- Existing Python configuration, migration, persona sharing, and image history.
- always / cached_only / hybrid / pre_generate image modes.
- POSIX shell and PowerShell launchers for Python 3.10+.
- An offline Windows/macOS/Linux CI matrix and package-content tests.

## Downloads to attach after review

- `persona-review-0.4.0-rc.1.zip`: standalone plugin directory.
- `persona-review-marketplace-0.4.0-rc.1.zip`: local marketplace with catalog.
- `SHA256SUMS`: hashes for both archives; verify against the reviewed build.

For first installation, expand the marketplace ZIP, enter its
`persona-review-marketplace` directory, and use the README's three CLI commands.
Use a compatible signed-in Codex and start a fresh session after installation.
Confirm both skills are discoverable before starting configuration or a review.

## Requirements and known limits

Python 3.10+ is still required. The shell launchers are not a Bash implementation;
Python-free fallback is not included. No runtime is installed automatically.
New expressions require Codex image generation and a registered reference image.
Without generation, the review explains the limitation; cached_only may reuse
valid saved images. The helper needs no API keys or external Python packages.

Baseline v0.3.0 passed its four Windows/Linux CI jobs and conditional Windows
first-install/live checks. These are not candidate results. Before moving this
draft forward, record the candidate commit, six-job CI URL/results, archive
hashes, independent review, and normal skill-discovery acceptance. Desktop final
image rendering and non-Windows live Codex integration remain unverified.

No personal images, settings, secrets, reviewed code, or raw model logs are
included. Repository public visibility and public-directory submission require
separate authorization; publisher/listing details are still to be confirmed.
